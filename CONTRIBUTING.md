# Contributing to TechBench

TechBench is currently in early development.

The project prioritizes:

- reproducible builds
- broad hardware compatibility
- mature existing Linux tools
- simple technician workflows
- offline functionality
- clear separation between safe and destructive operations

Changes should be tested before being merged.

Every included tool should solve a clear diagnostics, repair, recovery,
inspection or refurbishment requirement.

Avoid unnecessary duplicate utilities.

Prefer mature, maintained tools available through Debian where practical.
